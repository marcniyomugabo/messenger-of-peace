# Original photos

Original photos of the group, kept as source material. **The website does not use them.**
The pictures the website shows are in `client/public/images/` (resized for the web).

- Most are iPhone photos in **HEIC** format, which most web browsers cannot display.
  To use one on the website, convert it to JPEG, make it at most 1920 px wide,
  put it in `client/public/images/`, or upload it through the dashboard.
- `image/Leader/<name, position>/` folders say who is in the photo.
- `image/IMG_7215.JPG.jpeg` is a large (38 MB) original; the website uses smaller photos.
- `introduction/` holds an English version of the group handbook (not linked on the website).

These files used to be mixed into `client/src` together with copies of the website's pictures.
